# Functions:
- This app can automate your tasks for opening most used apps and making you able to save your precious time.
- You can open up apps by one button click on the keyboard.

# Keys:
- Use the F1 key to open up Google Chrome
- Use the F2 key to open up File Explorer
- Use the F3 Key to open up Terminal
- use the F4 Key to open up Notepad
- Use the F5 Key to open up Power Shell
- Use the F6 Key to open up the menu of everything it can open
- Use the F7 Key to open up Task Manager.
- Use the Print Screen to Open UP Youtube.
- Use the Scroll Lock to open up Instagram
- Use the Pause button to open up ChatGPT
- Use the Del key of Num Pad (while numlock is on) to open up 10 Fast Fingers.

# Installation:
- Install the .exe directly or compile the .ahk to .exe
- Move the file to the startup folder or just Press Win + R; type "shell:startup" and paste your file there.

# Modifying:
- Open the .ahk file
- Edit the apps or websites.
- Install the ahk to exe convert from https://github.com/AutoHotkey/Ahk2Exe/releases/tag/Ahk2Exe1.1.37.02a2
- Download the .zip file
- Open the zip file, and open the ahk2exe file
- Select the ahk file where you saved it. Follow the instructions and build it (change the version selection from the ahk2exe if any error appeared)
- Move the new created file to the startup folder (shell:startup) and then replace it.
